# 팝드론 태블릿 앱

팝드론 장비를 조작하는 안드로이드 태블릿 앱입니다.

## 내려받기

**늘 최신 버전:** https://github.com/POP-DRONE/popdrone-tablet-app/releases/latest/download/popdrone.apk

태블릿 크롬에서 위 링크를 열어 내려받고 설치합니다. "출처를 알 수 없는 앱" 안내가 나오면 허용해 주세요.

## 처음 쓸 때

1. 앱을 열고 위치 권한을 허용합니다(안드로이드가 와이파이에 자동으로 붙으려면 필요합니다).
2. 장비 번호를 고릅니다(기본 1번). 앱이 그 장비의 와이파이에 자동으로 붙습니다.
3. 안드로이드 연결 확인 창이 뜨면 [연결]을 누릅니다. 장비마다 처음 한 번만 뜹니다.

이전 버전은 [Releases](https://github.com/POP-DRONE/popdrone-tablet-app/releases)에 있습니다.
